### ✅ Completed
- **Phase 01: Simulator Client, Validation & State Sync**
  - **`CircuitBreaker` (`sim/circuit.py`):** 3-state state machine (CLOSED, OPEN, HALF_OPEN) with failure thresholds, reset timeout, async context manager, and Prometheus gauge `fsip_breaker_state`.
  - **`SimClient` (`sim/client.py`):** Resilient async HTTP client with exponential backoff + jitter, `x-simulator-stale` detection, domain error bypass (doesn't trigger breaker for 4xx domain responses), and full API coverage.
  - **Validation & Quarantine (`sim/validation.py`):** Strong Pydantic v2 validation for all simulator entities, consistency cross-checks (`world_issues`), and `fsip_sim_invalid_responses_total` metrics.
  - **In-Memory Store (`state/store.py`):** `WorldState` ring buffers (maxlen 2000 per station/fuel), degraded reasons, and full public JSON serialization matching `21_API_CONTRACTS.md`.
  - **Sync Loop & SSE Listener (`state/sync.py`, `sim/sse.py`):** Tick-based sync loop with strict coalescing (at most 1 running + 1 pending), simulator reset detection, keepalive handling, and supervised background tasks in engine `main.py`.
- **Phase 02: Persistence, Redis Snapshot & Operator API**
  - **Database Models (`db/models.py`):** 18 SQLAlchemy 2 async models covering all entities (`sim_runs`, `world_snapshots`, `demand_observations`, `decisions`, `alerts`, `incidents`, `ledger`, `quarantine`, etc.).
  - **Write Buffer (`db/buffer.py`):** Asynchronous non-blocking queue (5,000 items capacity) with batch commits and exponential backoff retry on database downtime.
  - **Redis Publisher (`state/publisher.py`):** Live snapshot caching (`fsip:state`), tick pointer (`fsip:state:tick`), and Redis Stream fanout (`fsip:domain-events`).
  - **Operator API (`services/api`):** Full FastAPI service with `/api/state` (ETag caching + DB fallback), `/api/stream` (SSE via Redis streams), node inspectors (`/api/stations/{id}`, `/api/depots/{id}`), rate-limiting middleware (600 req/min), and `/api/system/status`.
- **Comprehensive Test Suite:**
  - `services/engine`: 15 passed unit tests (circuit breaker, client retry, stale headers, validation, coalescing).
  - `services/api`: 7 passed unit tests (`/api/state`, ETag 304, 404 handlers, health).
  - `services/intelligence`: 1 passed unit test.
  - `frontend`: 5 passed unit tests + clean production build.
  - Total: 28 backend tests + 5 frontend tests all green!
